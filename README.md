# CTS Digital Nurture Upskilling Program
CTS Digital Nurture Upskilling Program – Practice exercises in Core Java, SQL, HTML, CSS, Bootstrap, and JavaScript.

## Overview

This repository contains a collection of Java programs and hands-on exercises completed as part of the CTS Upskilling learning program. It covers a wide range of Core Java concepts, starting from basic syntax and control structures to object-oriented programming, exception handling, collections, multithreading, file operations, JDBC, and modern Java features.

The primary objective of this repository is to strengthen programming fundamentals through practical implementation and provide a structured reference for commonly used Java concepts and coding patterns.

## Topics Covered

- Java Basics and Syntax
- Variables, Data Types, and Operators
- Conditional Statements and Loops
- Methods and Recursion
- Arrays and Strings
- Object-Oriented Programming (Classes, Objects, Inheritance, Interfaces)
- Exception Handling and Custom Exceptions
- File Input and Output
- Collections Framework (ArrayList, HashMap)
- Multithreading and Concurrency
- Lambda Expressions and Stream API
- Records and Pattern Matching
- JDBC Database Connectivity
- Transaction Management
- Client-Server Programming
- HTTP Client API
- Reflection and Bytecode Inspection
- Virtual Threads and Modern Java Features
